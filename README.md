> **Официальное специальное издание Forbes (г. Дрезна, Московская область)**

## 📸 Скриншот и структура файлов

Для корректного отображения портрета Алексея Захарова файл фотографии должен находиться в корневой директории репозитория под именем `3170.png`:

```text
├── 3170.png         # Фотография Алексея Захарова (портрет в костюме)
└── README.md        # Документация проекта
```

## 🚀 Быстрый запуск

### Вариант 1: Локально в браузере
1. Клонируйте репозиторий или скачайте архив:
   ```bash
   git clone https://github.com/YOUR_USERNAME/forbes-drezna.git
   cd forbes-drezna
   ```
2. Убедитесь, что файл `3170.png` лежит в той же папке, что и `index.html`.
3. Просто дважды кликните по `index.html` или откройте его через любой браузер.

### Вариант 2: Локальный веб-сервер (рекомендуется)
Если вы используете расширение **Live Server** в VS Code или Python:

```bash
# Для Python 3
python -m http.server 8000
```
Затем перейдите по адресу: [http://localhost:8000](http://localhost:8000).

## 🌐 Публикация на GitHub Pages (бесплатный хостинг)

Вы можете опубликовать сайт в интернет за пару кликов:

1. Загрузите файлы `index.html`, `3170.png` и `README.md` в ваш репозиторий на GitHub.
2. Перейдите в **Settings** (Настройки репозитория) → раздел **Pages** (слева в меню).
3. В блоке **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** выберите `main` (или `master`) и папку `/(root)`
4. Нажмите **Save**.
5. Через 1-2 минуты ваш сайт станет доступен по ссылке вида:  
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
